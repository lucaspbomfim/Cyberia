# Frontend

Interface web do Cyberia — conecta os 3 microsserviços.

**Responsável:** Lucas  
**Stack:** React

## Funcionalidades

- Login / Registro (via User Service)
- Upload de músicas (via Music Service)
- Listagem e player de áudio (via Music Service)
- Criação e visualização de playlists (via Playlist Service)

## Como rodar

```bash
npm install
npm start
```

Roda na porta `3000`.
